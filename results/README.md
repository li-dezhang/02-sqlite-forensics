# Actual results

`final-20261021/` is the published-candidate pilot result set, generated by real tool executions. `samples.csv` gives eligibility and source hashes; `per_case.csv` and `comparison.csv` report strict metrics; `truth.csv` and `record_matches.csv` make scoring inspectable; `run.json` records commands, exit codes and hashes. `by_condition.csv`, `real_tolerance_sensitivity.csv` and `FAILURE_ANALYSIS.md` explain scope and failures.

Development and repeat runs remain locally available but are Git-ignored. Original tool output is under ignored `data/interim/runs/`. No result has been invented or promoted to an independent human approval. The 131 non-0C databases were not evaluated.
