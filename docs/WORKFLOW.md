# P2 lightweight research workflow

Effective 2026-10-21 under the user’s explicit instruction in this conversation. P2 only; P1/P3/P4/P5 remain frozen.

1. Acquire the official public SQLite Forensic Corpus v2.0 (maximum 20 MB download), after checking source and basic licence.
2. Write Python analysis code and independently validate deleted-record reference data.
3. Run real, reproducible experiments using two independent public tools.
4. Generate measured tables, figures and failure analyses.
5. Write an English research report based only on those outputs.
6. Prepare local GitHub-ready files; no remote creation or push.

Historical Gate A was never approved. The unchanged authorization template and old gate documents are historical and do not govern this newly authorized lightweight workflow. No old APPROVED decision or reviewer signature is created. No new approval form is required.

Stop if the official source/licence is incompatible, access controls would need bypassing, reliable deleted-record truth is unavailable, or two methods cannot be compared honestly. Use isolated local dependencies, immutable original data, safe bounded extraction, and do not execute supplied SQL or unknown data files. No private/case data. Score with one-to-one matching; report incomplete and ambiguous outputs explicitly.

Minimum checks: executable Python, scoring unit tests, real input/output logs, table/figure/report agreement, working README commands. Publication remains a separate user decision.
